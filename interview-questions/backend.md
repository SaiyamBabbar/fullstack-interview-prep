# Backend Interview Questions

## Q1. What is REST?

REST is an architectural style for designing networked applications
using resources and standard HTTP methods.

## Q2. What is the difference between authentication and authorization?

Authentication verifies who the user is.

Authorization determines what the user is allowed to do.

## Q3. What is JWT?

JWT is a compact token format commonly used to transmit claims
between parties.

## Q4. What is pagination?

Pagination divides a large dataset into smaller portions instead
of returning everything in a single response.

## Q5. What is caching?

Caching stores frequently accessed data temporarily so that future
requests can be served faster.
