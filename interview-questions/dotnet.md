# .NET Interview Questions

## Q1. What is Dependency Injection?

Dependency Injection is a design pattern where dependencies are
provided to a class instead of the class creating them itself.

## Q2. What is middleware in ASP.NET Core?

Middleware is part of the HTTP request pipeline.

It can inspect, modify, or handle HTTP requests and responses.

## Q3. What is Entity Framework Core?

Entity Framework Core is an ORM that allows .NET applications
to work with databases using .NET objects and LINQ.

## Q4. What is the difference between IEnumerable and IQueryable?

`IEnumerable` generally performs operations in memory.

`IQueryable` can translate expressions into queries that are
executed by the underlying data source, such as SQL Server.

## Q5. What is LINQ?

LINQ provides a way to query collections and data sources using
C# syntax.
